# Weather-app

## Summary
For the development of this app we will be using 2 free API's. [Open-Meteo-Weather](https://open-meteo.com/en/docs?hourly=&timezone=auto&current=temperature_2m&daily=weather_code,temperature_2m_max,temperature_2m_min&latitude=40.48205&longitude=-3.359972) and [Open-Meteo-Geocoding](https://open-meteo.com/en/docs/geocoding-api?name=Alcal%C3%A1+&language=es#json_return_object)

The **Geocoding** API we will be used to extract coordinates from the requested city by the user, and afterwards that coordinates will fetch data from de **Weather** API to be shown in the UI.
