# html-css-js-practice
HTML, CSS &amp; JS mini projects built while practicing front-end fundamentals.

A collection of small front-end projects built while practicing HTML, CSS, and JavaScript fundamentals before moving on to React.


## Projects
Each folder is a self-contained mini project — no build tools or dependencies, built through hands-on practice rather than tutorials alone.

Each project folder includes its own set of files and, when relevant, a short note inside its index.html or a local README.md explaining what was practiced and any challenges faced.

## Notes
These projects are for practice purposes; some are inspired by common exercises or tutorials and adapted while learning.
